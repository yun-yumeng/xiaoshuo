## 网站开发：不是贱贱的私密小窝（静态小站）
- 目标：共享文件 + 小说章节，部署到 GitHub + Cloudflare Pages，页面简洁、支持图片。
- 技术：纯静态、零构建。index/novel/files 三页 + content/*.json 驱动 + chapters/*.md|txt|图片 + files/ 下载。
- 关键文件：assets/js/markdown.js（零依赖 md 渲染）、assets/js/app.js（主题/灯箱/加载）、assets/css/style.css（:root 主题变量，纯色背景）。
- 小说页支持多类型章节：md 渲染 / txt 纯文本 / 图片直显 / doc|docx（Office Online 内嵌预览+下载）。
- 站点名已改为「不是贱贱的私密小窝」（三页标题/导航/页脚统一）。
- 部署：CF Pages 连 Git（构建命令留空，部署目录 `/`）；或 wrangler pages deploy .；_headers 已放缓存规则。
- 本地预览：python3 -m http.server 8000（不能用 file:// 打开，浏览器禁读内容文件）。
